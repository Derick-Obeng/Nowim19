# Nowim19 - React Native Frontend 🚀

---

This is the mobile frontend for Nowim19, built using React Native.

---

## 📌 Features
⚡ Fast & responsive UI
📱 Supports both Android & iOS
🎨 Styled with React Native components


---
 ## 🔧 Setup & Installation
Clone the repository:


git clone https://github.com/Derick-Obeng/Nowim19.git
cd Nowim19

---

Install dependencies:


npm install
Run the app on Expo:


npm start

---

Scan the QR code in Expo Go (for iOS & Android).
If using an emulator:

npx expo start --android
